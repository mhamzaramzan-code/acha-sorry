# Apology site — Netlify-ready

## Personalize it

Open `index.html` in any text editor and replace:

- `My Love` with your partner’s name or nickname.
- `[Your Name]` with your name.
- The four memory cards with real moments from your relationship.
- Any part of the letter that you want to make more specific.

Look for comments beginning with `PERSONALIZE` to find the editable areas quickly.

## Publish on Netlify

1. Keep all files together.
2. Zip the contents of this folder, or drag the folder directly into Netlify Drop.
3. In Netlify, open **Domain management** and add the domain you already own.
4. Follow Netlify’s displayed DNS instructions at your domain registrar.

The ambient music is generated in the visitor’s browser and only begins after they press the sound button. It uses no copyrighted recording.
